Nexus

A native macOS menu bar toolkit: Pomodoro timer, image uploader, time tracker, and command palette in one small app.

Open your days GitHub 

brew install --cask lightblues/tap/nexus

Pomodoro

Projects, tasks and tags, a menu bar countdown, and stats by day and project.

Time tracker

Which app, project, file and site had your attention, sampled from the front window. Lock screen and idle time are left out.

Image uploader

Drop or paste an image; it is compressed, pushed to a GitHub repo, and its CDN link is on your clipboard.

Command palette

One hotkey for every Nexus action.

Your server

Every Mac syncs to a small server you run. It turns raw activity into one summary per day: time by category, project and site, focus blocks, and pomodoros.

For agents

The nexus CLI and a read-only export let your agents and other tools ask what you did today, without touching your Macs.

Nexus is personal software. The web app here is read-only; sign in with a sync key.
