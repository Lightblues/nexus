# 几个关键设计决定
1. 保持 bundle ID site.easonsi.nexus — 用户 AX 授权无缝继承,不再有 v0.5.0 那次重命名的痛。
2. 不用 SwiftUI MenuBarExtra — uploader 的 drop receiver 和 1Hz 标题写入要 NSStatusItem 直控。
3. 单 target,无 XPC — 不再现 Electron 多进程的内存税,也避开 ADR-011 嵌套签名陷阱。
4. AX API 替代 AppleScript — ADR-001 的根因(多二进制权限)在单签名二进制下消失;每次轮询从 ~50ms → ~1ms,浏览器 URL 仍走 Apple Events 但用预编译 NSAppleScript 缓存(~5ms)。
5. Universal binary — 一份 DMG / 一个 sha256 / Cask 去掉 arch 块,简化发布流水线。
6. Sparkle 自动更新 — 给非 Homebrew 用户也提供升级路径,~3MB 加成可接受。
7. 数据格式向后兼容 — 旧的 data.json/tracker/*.json/uploader.json 不需要迁移工具,首启动写入时一次性写规范化的 schema,并保留 .electron-bak 兜底。
