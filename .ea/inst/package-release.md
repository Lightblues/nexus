疑问 1. 为什么需要这么多大小的图片? 2. 这些图片需要放进 git ignore 吗
```sh
# macOS 在 5 个 UI 位置 × 2 套显示密度 (Retina/非 Retina) 直接挑最匹配那张,不做重缩放:
- 16 → Finder 列表 / 菜单栏菜单
- 32 → Spotlight / Finder 中等
- 128 → Finder 大图标
- 256 → CMD-Tab / Mission Control
- 512 → 启动台 / 关于本机 / Dock
每个尺寸都 ×2 是因为 Retina 屏要同物理大小但 4 倍像素。所以 16 那一档实际上要 16px 和 32px 各一张。
```
